## How to use
1. **Set up API keys and secrets** (IMPORTANT):
   - Copy the `Keys.example` directory to `Keys`
   - Edit all files in the `Keys` directory with your actual credentials
   - See [SECURITY.md](SECURITY.md) for detailed instructions

2. Deploy the website on your environment.

3. Open up server.

4. Try running to see the results.

5. The results will be saved to tickets to store as important datas for training AI.

## Security

⚠️ **IMPORTANT**: This project requires API keys and secrets that must be configured before use.

- All sensitive credentials should be placed in the `Keys/` directory (gitignored)
- Never commit API keys, secrets, or credentials to version control
- See [SECURITY.md](SECURITY.md) for complete security guidelines
- Use example files in `Keys.example/` as templates

For detailed security setup and best practices, please read [SECURITY.md](SECURITY.md).
